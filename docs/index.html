F-Fold

An AlphaFold3-architecture model whose hyperparameters are machine-verified against OpenFold3-preview — and small enough to train, not just run, on a single 15 GB GPU.

Source on GitHub Alignment evidence Measured results Limitations

What this is

F-Fold is an independently written implementation of the AlphaFold3 architecture — Pairformer, MSA module, template stack, diffusion module and all five confidence heads — at the exact tensor dimensions used by OpenFold3-preview, the AlQuraishi Lab / OpenFold consortium's Apache-2.0 AF3 reproduction. It ships with a distillation pipeline that turns AlphaFold DB structures into your own trained weights.

What it is not: a competitor to AlphaFold on accuracy. The trained preset is distilled from AlphaFold, so AlphaFold is its ceiling by construction, not its benchmark. It has no MSA search, no templates, and no all-atom output in the trained path. The structures it produces today are not correct folds — see measured results, where we report that plainly. If you need accurate structures, use AlphaFold2, OpenFold3, Boltz-2 or Chai-1.

What F-Fold offers instead is reproducible architectural fidelity at a hardware tier where AF3-class models are otherwise unreachable, with every number on this page generated by a script in the repository.

Hyperparameter alignment

ffold/config.py is written by hand against the AF3 specification. It is deliberately not generated from OpenFold3's config — that is what makes the comparison a test rather than a tautology. ffold/check_alignment.py extracts the reference from the openfold3==0.4.1 source distribution, diffs every shape-bearing field, and exits non-zero on any disagreement, so it can run in CI.

$ python ffold/check_alignment.py
           match: 203
$ echo $?
0

Kernel selection, memory offloading, activation checkpointing and weight-initialisation policy are explicitly excluded — they do not change tensor shapes. Everything that does is compared. The base dimensions:

FieldValueFieldValue
c_s — single/token384 c_atom128
c_z — pair128 c_atom_pair16
c_m — MSA64 c_token_embedder384
c_t — template64 c_token_diffusion768
c_s_input449 sigma_data16

Stack depths: Pairformer 48 blocks (16 pair-bias heads, c_hidden 24); diffusion transformer 24 blocks (16 heads, c_hidden 48); MSA module 4; template pair stack 2; confidence Pairformer 4; atom encoder and decoder 3 each. Label spaces: distogram 64 bins over 2–22 Å, pLDDT 50 bins, PAE and PDE 64 bins over 0–32 Å. Diffusion follows the EDM schedule with s_max 160, s_min 4×10⁻⁴, p 7.

Measured results

A 1,723-structure teacher set was built from AlphaFold DB v6 (retrieved 2026-10-24): reviewed UniProt sequences of 60–256 aa, k-mer-deduplicated at a 0.30 shared-5-mer ceiling, with models below mean pLDDT 70 discarded as predicted disorder rather than folds. Human lysozyme C (P61626, 148 aa, teacher mean pLDDT 94.1) was held out and excluded from training by both accession and sequence similarity.

ffold-mini was trained on one Tesla T4 with AMP and gradient checkpointing, batch 8 at crop 160. The run was stopped by a 2-hour wall clock at step 2,000 of 8,000, so these numbers describe a quarter-trained model, not a converged one.

The control matters more than the headline. Feeding the teacher's own distance matrix through the identical MDS-plus-refinement reconstruction recovers the structure to 1.19 Å. The reconstruction code is therefore sound, and the 14.31 Å result is attributable to the model's predicted distances — specifically its missing long-range contacts — rather than to a bug in the geometry pipeline. That is the distinction a reviewer would ask for first.

Limitations, stated plainly

  • It does not predict usable structures. TM-score 0.200 means the fold is wrong. This is a pipeline and an architecture, not a structure predictor you should deploy.
  • A student cannot exceed its teacher. Distillation from AlphaFold bounds accuracy by AlphaFold. Claims of superiority over AlphaFold would be unsupportable and are not made anywhere in this project.
  • Trained for 2,000 steps on 1,550 structures (172 held for validation, 1 for test). AlphaFold3 was trained on the PDB with deep MSAs over orders of magnitude more compute. The gap is expected, not anomalous.
  • No MSA, no templates, no all-atom output in the trained path. Those modules are implemented and parameter-audited, but the distillation runs protein-only and token-level.
  • ffold-base has never been trained — only audited for parameter count and forward-pass shape correctness. Training it needs hundreds of GPU-days.
  • Single held-out protein. One 148-residue monomer is an illustration, not an evaluation set.

Reproduce it

git clone https://github.com/zhu-algorithm/f-fold
cd f-fold && pip install -r requirements.txt

python ffold/check_alignment.py     # 203/203, exit 0
python ffold/audit_params.py        # parameter table

python ffold/build_dataset.py --n 2800 --min-plddt 70
python ffold/train.py --auto-batch --amp --grad-checkpoint --crop 160
python ffold/evaluate.py            # metrics vs the AlphaFold teacher
